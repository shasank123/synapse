Getting started

From install to a running MCP server in four steps.

1 · Install the CLI

Requires Python 3.11+.

$ pip install synapse-cli

2 · Create an API key

Generate a key from your dashboard, then configure the CLI.

$ synapse init
$ synapse config --key syn-api-…

3 · Analyze your codebase

AST parse + embed + index — runs locally, your source never leaves your machine wholesale.

$ synapse analyze
✓ Scanned codebase · indexed for semantic search

4 · Build & run your MCP server

Select the detected tools, generate, then plug the server into any MCP host.

$ synapse build
✓ mcp_server.py generated
$ python mcp_server.py

Self-hosting the backend

Run the full platform locally with Docker Compose (Postgres · Redis · Qdrant · MinIO · gRPC · API · worker), then point the CLI's config.json at localhost:50051 / localhost:8000.

$ docker compose up --build
