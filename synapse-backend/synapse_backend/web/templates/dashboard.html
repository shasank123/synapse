🔌 Connect to an MCP host

Once synapse build writes your {{ srv }}, register it with Claude Desktop, Cursor, or any MCP host. Paste this into the host's config, then restart it — your tools appear as natural-language actions.

MCP host config 
{
  "mcpServers": {
    "{{ srvkey }}": {
      "command": "python",
      "args": ["/absolute/path/to/{{ srv }}"]
    }
  }
}
Claude Desktop

Edit the config file, then restart Claude Desktop:

macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json
Cursor / Windsurf / Continue

Add to the project or user MCP config:

Cursor: .cursor/mcp.json (or ~/.cursor/mcp.json)
Continue: ~/.continue/config.json

💡 Replace /absolute/path/to/{{ srv }} with the full path where you ran synapse build. Prefer a venv Python that has your project + mcp installed.
